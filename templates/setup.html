Connect SQL Server

The pages need a local Microsoft SQL Server database before they can read or write rows.

  1. Install SQL Server (Developer or Express) and SSMS on your laptop.
  2. Copy .env.example to .env. Set DB_SERVER (often localhost or .\SQLEXPRESS) and keep DB_TRUSTED=yes for Windows login.
  3. Install the ODBC Driver for SQL Server, then run pip install -r requirements.txt.
  4. Create the tables with python init_db.py. Or open schema.sql and seed.sql in SSMS against the FreelanceMarketplace database.
  5. Start the site with python app.py and open http://127.0.0.1:5000.

The Tables page explains the nine tables and does not need the database.
