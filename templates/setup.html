Connect the database

The pages need a Neon connection string before they can read or write rows.

  1. Create a free project at neon.tech. Choose PostgreSQL, which is the only database Neon offers.
  2. Open Connect and copy the connection string.
  3. Copy .env.example to .env and paste the string as DATABASE_URL.
  4. In the Neon SQL editor, run schema.sql and then seed.sql. Or, from this folder, run python init_db.py.
  5. Start the site with python app.py and open http://127.0.0.1:5000.

The Tables page explains the nine tables and does not need the database.
